# Stellar vectors

`rfc8032-ed25519.json` contains the published PureEd25519 TEST 1 and TEST 2 from
[RFC 8032 section 7.1](https://www.rfc-editor.org/rfc/rfc8032#section-7.1).

`sep-0005.json` contains all 50 published seed/address pairs from
[SEP-5 at 1ae39233055a0fb94bb737650a39ede8d77d924c](https://github.com/stellar/stellar-protocol/blob/1ae39233055a0fb94bb737650a39ede8d77d924c/ecosystem/sep-0005.md).
The fixture records the source SHA-256 and original case/path labels. `seedHex`
and `publicKeyHex` were extracted from the published S/G strings using Python's
Base32 decoder with version and CRC-16/XMODEM checks. Mnemonic and HD derivation
are outside this module.

`sep-0023.json` contains published StrKey vectors from
[SEP-23 at 1ae39233055a0fb94bb737650a39ede8d77d924c](https://github.com/stellar/stellar-protocol/blob/1ae39233055a0fb94bb737650a39ede8d77d924c/ecosystem/sep-0023.md).
The JSON records the SHA-256 of the source document. G and M keys are account
addresses; the other published key types are rejected by the account address API.

`stellar-sdk-17.4.0.json` is generated by the SDF-maintained
[`@stellar/stellar-sdk` 17.4.0](https://www.npmjs.com/package/@stellar/stellar-sdk/v/17.4.0),
licensed under Apache-2.0. These are independently generated expectations, not
published protocol vectors. All seeds are fixed public test values.

The generator records envelopes, hashes, operation and memo bytes, signatures and
muxed addresses. See the [coverage matrix](../../README.md) for tested protocol
variants. Some fixtures are structurally valid historical or isolated operation
examples; they do not assert acceptance by a current node.

Network ID expectations in `XlmNetworkTest` are SHA-256 digests of the exact UTF-8
passphrases, independently calculated with Python `hashlib`.

`XlmXdrCodecTest` contains hand-written byte expectations derived from RFC 4506
sections 4.1, 4.2, 4.5 and 4.10. They are scalar encoding examples rather than
published transaction vectors. `SHA256SUMS` pins the JSON fixtures and generator.

To regenerate with Node.js and the pinned SDK installed outside the repository:

```bash
npm install --prefix /tmp/stellar-oracle --ignore-scripts --no-audit --no-fund @stellar/stellar-sdk@17.4.0
node xlm/src/test/resources/vectors/generate.mjs /tmp/stellar-oracle/node_modules/@stellar/stellar-sdk/lib/esm/index.js
```
