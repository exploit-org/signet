# Typed transaction signing vectors

`typed-transactions.json` is generated by the independent ethers.js SDK, version
6.15.0 (MIT), using the adjacent generator. These are SDK-generated expectations,
not published Ethereum protocol vectors. They pin the signing preimage, signing
hash, deterministic signature, signed bytes and transaction hash for types 1 and 2.
Cases include empty and duplicate access lists, contract creation and a chain ID
larger than uint64. The private key is a public test key (`46` repeated 32 times).

SHA-256 of `typed-transactions.json`:
`27454ab88aa61e5eb31c16ffbe23057640721d02d80ec2891ba4fe5ebee07693`.

To regenerate, install `ethers@6.15.0` in a temporary directory and run:

```sh
NODE_PATH=/path/to/temp/node_modules node generate-typed-transactions.cjs > typed-transactions.json
```

No SDK or network access is required for normal Gradle tests. Existing published
Ethereum vectors remain in `OfficialTransactionVectors.java` with upstream revision
references and are checked by the parser suite.

Protocol references: [EIP-2930](https://eips.ethereum.org/EIPS/eip-2930),
[EIP-1559](https://eips.ethereum.org/EIPS/eip-1559).
SDK source: [ethers v6.15.0](https://github.com/ethers-io/ethers.js/tree/v6.15.0).
